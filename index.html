    How it works

    Four steps from a city name to an outfit. No account and no API key.

    1. Find the placeThe Open-Meteo Geocoding API turns your city name into coordinates.
    2. Get the weatherThe Forecast API returns current conditions and a 6-day outlook.
    3. Run the engineFeels-like temperature is adjusted for your activity and comfort, then scored against the rules.
    4. Explain the resultEach item in the outfit comes with a plain-language reason.
    Explainable adviceYou see why, not just what.
    Activity modesCasual, office, workout and travel outfits differ.
    Personal comfortShift advice if you feel cold or hot easily.
    Rain, UV and windAdds umbrella, sunscreen or a windbreaker when needed.
    5-day outlookPlan ahead, in °C or °F.
    Private by designNothing is sent to us. Only the last city is kept in your browser.

    The recommendation rules

    The engine is a rule-based expert system. It maps the adjusted feels-like temperature to a base outfit, then adds extras for rain, UV, wind and humidity.

    Feels likeTopBottomExtras
    32°C and aboveLight cotton or linen teeShorts or thin trousersSandals, hydration
    27 to 31°CCotton t-shirtLight trousersSneakers
    20 to 26°CTee with thin overshirtJeans or chinosSneakers
    14 to 19°CFull sleeve with light jacketJeansClosed shoes
    8 to 13°CSweater with warm jacketLined trousersScarf
    Below 8°CThermal, sweater, heavy coatThermal-lined trousersBeanie, gloves, boots
    Adjustments
    • Workout: +5° (the body heats up)
    • Cold or hot easily: -3° or +3°
    • Office: formal pieces replace casual ones
    Add-ons
    • Rain chance 30% or more: umbrella. 60% or more: raincoat too
    • UV index 6 or more: sunglasses, cap, sunscreen
    • Wind 30 km/h or more: windbreaker

    Security and privacy

    Small apps still need safe defaults. These are built in.

    Content-Security-PolicyThe page can only contact the two Open-Meteo hosts.
    Input validationCity names pass an allow-list filter and a 60-character limit.
    No XSS surfaceResults are written with textContent, never innerHTML.
    No secretsNo API key or credentials exist in the client code.
    Minimal storageOnly the last city is saved locally. No cookies, no tracking.
    Permission firstLocation is requested only when you tap the button.

    Frequently asked questions

    Is this real AI?

    It is a rule-based expert system, a classic branch of AI. It decides from weighted rules and explains each decision. Machine learning is listed as future scope.

    Where does the weather data come from?

    Open-Meteo, a free open weather service that needs no API key.

    Does the site store my location?

    No. Your coordinates are used only to request the forecast. The last city name is kept in your own browser.

    Why does "Use my location" not work?

    Browsers may block location on files opened directly. Run a local server (python -m http.server 8000) or host the site on HTTPS, such as GitHub Pages.
